# Dicionário de dados

## demografia_anual_municipal.csv
- `cod_ibge`: código IBGE de 7 dígitos
- `municipio`: município
- `ano`: ano do evento
- `nascimentos`: nascidos vivos registrados
- `obitos`: óbitos registrados
- `populacao`: população estimada quando disponível
- `saldo_natural`: nascimentos − óbitos
- `natalidade_por_mil`: nascimentos / população × 1.000
- `mortalidade_por_mil`: óbitos / população × 1.000
- `crescimento_natural_por_mil`: saldo natural / população × 1.000

## estrutura_etaria_2022.csv
- `0-14`, `15-59`, `60+`: população agregada por grupo etário
- `prop_jovens_pct`: percentual de 0–14
- `prop_idosos_pct`: percentual de 60+
- `indice_envelhecimento`: idosos por 100 jovens

## nascimentos_idade_mae.csv
Registros de nascimentos por município, ano e categoria de idade materna.
